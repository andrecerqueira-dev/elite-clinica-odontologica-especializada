# ✨ Elite Clínica Odontologia Especializada

### Sofisticação, cuidado e excelência em saúde bucal.

Um projeto de website institucional desenvolvido para uma clínica odontológica especializada, com uma proposta visual elegante, moderna e acolhedora, transmitindo confiança, profissionalismo e credibilidade aos pacientes.

## 📸 Sobre o projeto

O **Elite Clínica** foi desenvolvido com foco em uma experiência digital agradável, intuitiva e responsiva, valorizando a identidade visual da clínica e facilitando o acesso dos pacientes às informações e aos serviços oferecidos.

O projeto busca unir estética, funcionalidade e organização, proporcionando uma navegação simples e eficiente.

## 🚀 Funcionalidades

- Design moderno e sofisticado.
- Layout responsivo.
- Navegação intuitiva.
- Apresentação dos serviços odontológicos.
- Seção institucional sobre a clínica.
- Área de depoimentos de pacientes.
- Informações de contato e localização.
- Elementos interativos com JavaScript.

## 🛠️ Tecnologias utilizadas

- **HTML5** — estruturação do conteúdo.
- **CSS3** — estilização, layout, responsividade e efeitos visuais.
- **JavaScript** — interatividade e funcionalidades.
- **Git e GitHub** — versionamento e gerenciamento do projeto.

## 🎨 Identidade visual

A proposta visual utiliza uma combinação de tons neutros, bege e dourado, criando uma identidade elegante e sofisticada, alinhada ao posicionamento da clínica.
